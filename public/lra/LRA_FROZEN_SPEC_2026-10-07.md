## 凍結内容

- ブランド表示：LRA / ライフレビューアセスメント
- `LRA / 001` 表記は使用しない
- 生成り紙色を基調としたエディトリアルデザイン
- 明朝中心の大見出し
- 細い黒線、同心円、構造図、広い余白
- 利用者向け表示文は自然な日本語を優先する
- 内部用の英語ラベルや専門語を利用者向け画面へそのまま出さない
- ナビゲーション：LRAとは / 進め方 / 料金
- ファーストビュー：`暮らしを、点ではなく構造で捉える。`
- 進め方：全体を確認 → 必要なところを詳しく確認 → 出来事の流れを整理 → 全体のつながりを整理
- 結果表示は、専門用語ではなく利用者が理解しやすい日本語へ翻訳する
- 料金：無料体験 0円 / ライト 980円 / スタンダード 2,980円 / ディープ 5,980円 / 継続分析 9,800円
- 導線：トップ → 料金 → プラン選択 → LRA開始 → 基本確認
- 利用規約、プライバシーポリシー、特定商取引法に基づく表記をサイト内で展開可能
- 回答はブラウザ側localStorageへ保存
- 公開方式：GitHub Pages

## 文言ルール

- `CORE SCAN` 等の内部名称は利用者向けには自然な日本語へ置き換える
- `CHAIN / LOOP`、`ボトルネック`、`レバレッジ`、`介入` 等の専門語を、そのまま顧客向け表示に使用しない
- 法務表示を除き、説明文は日常語を基本とする
- 利用者に診断・評価・判定されている印象を与えない
- LRAの機能説明は、何を確認し、何が整理され、次に何を判断できるかが分かる文章にする
